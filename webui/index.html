About

tgpilot is a free, open-source tool for Telegram Serverless bots: write the code in a plain folder and deploy, run, migrate and keep an eye on it — from the terminal or from this studio. Everything stays on your machine; the bot token never leaves it. Made with care by the CyberRage team.
