How this machine reaches the cloud

If cloud.telegram.org is blocked on this network, send the traffic through a proxy. Both HTTP and SOCKS5 proxies work — the kind is detected automatically. Leave the field empty to connect directly.

run a test to see where the chain breaks

Remote servers

On a remote machine there is usually no proxy running on it. Either start one there, or tunnel your own machine's proxy through SSH: ssh -R 10809:127.0.0.1:10809 user@server — then use socks5://127.0.0.1:10809 here.
